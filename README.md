## What we do

We meet weekly to learn robotics from scratch. No experience needed.

Right now we're learning Arduino, sensors, and how to make things move on their own.

---

## What we use

**Software (all free):**
- [Wokwi.com](https://wokwi.com) - Online simulations
- Arduino IDE - for uploading code to real boards
- This GitHub - all our code and guides

**Hardware:**
- Arduino-like boards
- LEDs, sensors, motors
- Breadboards and wires

We provide everything during sessions
